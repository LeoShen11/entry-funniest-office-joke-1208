One short line about office life: an employee asks HR for a raise and is handed a mindfulness app instead, so now they can calmly watch their salary stay exactly where it is. The program writes that single joke to `/output/entry.txt`, after checking it is one line of 1–200 characters and reading it back to confirm the file matches exactly.

## Run it

```sh
node main.ts
```

It writes the joke to `/output/entry.txt`. To check it locally without
touching `/output`, pass a path instead:

```sh
node main.ts ./entry.txt
```
